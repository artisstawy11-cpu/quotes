# عروض أسعار Designly

سيستم بيعمل عروض الأسعار ويطلعها PDF مباشرة من الجوال.
- **الاستضافة:** GitHub Pages، بنفس طريقة ميزان.
- **قاعدة البيانات وتسجيل الدخول:** Firebase بتاع ميزان (`mizan-designly`)، وبيانات العروض محفوظة في collections اسمها بيبدأ بـ `qs_`.

## التشغيل لأول مرة
1. اعمل repo جديد على GitHub باسم `quotes`، وارفع فيه `index.html` و`.nojekyll`. بعدين فعّل Pages من Settings ← Pages ← Branch: main.
   الرابط هيبقى: https://artisstawy11-cpu.github.io/quotes/
2. افتح Firebase Console ← Firestore ← Rules، والصق محتوى `firestore.rules` كله (فيه قواعد ميزان + قواعد العروض)، واضغط Publish.
3. ادخل على الرابط بحساب info@designly-agency.com. الكتالوج والإعدادات بيتعملوا لوحدهم من أول دخول.
4. من **الإعدادات**:
   - ارفع شعار ديزاينلي، وصورة شهادة الحساب البنكي، وصورة شعارات العملاء.
   - ارفع صور شركاء النجاح (روابطهم موجودة جاهزة).
   - حط مفتاح OpenAI API لو عايز الأتمتة الكاملة.
   - راجع الأسعار الافتراضية في الكتالوج.
5. عشان تضيف حد من الفريق: الإعدادات ← الفريق ← اكتب إيميله. لازم يكون عامل حساب في ميزان بنفس الإيميل.

## التجربة من غير Firebase
افتح `index.html?demo=1`، والبيانات هتتحفظ في المتصفح بس.
